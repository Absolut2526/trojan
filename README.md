# 🎮 PC Club Manager (Бот та Веб-панель керування ПК-клубом)

Комплексна система віддаленого моніторингу та керування комп'ютерами інтернет/ПК клубу через **Telegram-бота** та **веб-панель (дашборд)**.

---

## ⚡ Що вміє система:
- **🖱 Керування мишею віддалено:** рух, кліки (ліва/права/середня), подвійний клік, drag & drop і скрол прямо з трансляції екрану у веб-панелі.
- **📸 Скріншот екрану:** миттєвий знімок робочого столу прямо в Telegram або у вікно браузера.
- **🌐 Відкрити посилання:** віддалене відкриття будь-якого сайту (YouTube, Steam, сторінка акції тощо) у браузері за замовчуванням.
- **❌ Закрити процес:** примусове завершення ігор або програм за назвою (`dota2.exe`, `cs2.exe`, `chrome.exe`).
- **📋 Список процесів:** перегляд активних процесів із навантаженням на RAM та процесор.
- **🔄 Перезавантаження ПК** (із захистом від випадкового натискання).
- **⏻ Повне вимкнення ПК** (із підтвердженням).
- **🟢 Моніторинг статусу в реальному часі:** живий статус онлайн/офлайн та навантаження CPU/RAM.

## 🚀 Крок 1. Налаштування Telegram-бота

1. Відкрийте Telegram і напишіть боту [@BotFather](https://t.me/BotFather).
2. Надішліть команду `/newbot`, оберіть назву (наприклад, `CyberClub Manager`) та юзернейм (наприклад, `my_club_control_bot`).
3. Скопіюйте отриманий **API токен** (вигляду `1234567890:ABCdef...`).
4. Напишіть боту [@userinfobot](https://t.me/userinfobot), щоб дізнатися свій числовий **Telegram User ID** (наприклад, `456789123`).

---

## 🌐 Крок 2. Розгортання сервера на Render

1. Зареєструйтесь на [Render.com](https://render.com).
2. Створіть новий репозиторій на GitHub і завантажте туди папку проєкту `pc-club-bot`.
3. У Render натисніть **New +** ➔ **Web Service** ➔ підключіть ваш репозиторій.
4. Вкажіть налаштування:
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r server/requirements.txt`
   - **Start Command:** `python -m uvicorn server.main:app --host 0.0.0.0 --port $PORT`
5. У розділі **Environment Variables** додайте:
   - `BOT_TOKEN` = `ваш_токен_від_BotFather`
   - `ADMIN_IDS` = `ваш_telegram_id` (якщо кілька адмінів, через кому: `123456,789101`)
   - `CLIENT_SECRET` = вигадайте надійний пароль (наприклад `ClubPass2026!`)
6. Натисніть **Deploy Web Service**.
7. Після завершення розгортання Render видасть вам публічну адресу, наприклад:
   `https://pc-club-manager-xxxx.onrender.com`

> Веб-панель буде доступна за цим посиланням у браузері, а бот автоматично запуститься в Telegram!

## 🖥 Крок 3. Налаштування клієнта на ПК клубу (Windows)

Клієнт повинен працювати у фоні на кожному комп'ютері клубу.

### 1. Налаштування конфігурації
На комп'ютері створіть або відредагуйте файл `client_config.json`:
```json
{
    "server_url": "wss://pc-club-manager-xxxx.onrender.com/ws/client",
    "secret": "ClubPass2026!",
    "pc_name": "PC-01"
}
```
*Зверніть увагу на префікс `wss://` замість `https://`.* Для кожного комп'ютера змініть `pc_name` (`PC-01`, `PC-02` і т.д.).

### 2. Запуск через Python (швидкий тест)
```bash
cd client
pip install -r requirements.txt
python client.py
```

### 3. Компіляція в один файл `.exe` (для клубних ПК)
1. На Windows-комп'ютері запустіть скрипт `build_exe.bat` або виконайте:
   ```cmd
   pip install -r requirements.txt
   pyinstaller --onefile --noconsole --name "pc_client" client.py
   ```
2. У папці `dist/` з'явиться готовий файл `pc_client.exe`.
3. Скопіюйте `pc_client.exe` та `client_config.json` в одну папку на цільовому ПК (наприклад, `C:\ClubClient\`).
4. **Автозапуск разом із Windows:**
   - Натисніть `Win + R`, введіть `shell:startup` і натисніть Enter.
   - Створіть ярлик для `pc_client.exe` та помістіть його у цю папку автозавантаження.

## 🖱 Керування мишею через веб-панель

1. Відкрийте веб-панель у браузері та натисніть **⛶ Екран** на потрібному ПК (трансляція відкриється у великому вікні).
2. Натисніть у футері вікна кнопку **🖱 Миша: ВИКЛ** — вона стане синьою («УВІМК») і курсор над картинкою зміниться на хрестик.
3. Керуйте як звичайною мишею:
   - рух мишки над картинкою — рух курсору на ПК клубу;
   - ліва/права/середня кнопка, подвійний клік, перетягування (drag & drop);
   - колесо — скрол; правий клік не викликає меню браузера.
4. Вимкнути керування: кнопка **🖱 Миша: УВІМК** ще раз, клавіша **Esc** або закриття вікна трансляції.

> Керування за замовчуванням **вимкнене** — доки його не увімкнути, рух мишки по сторінці керує лише браузером.

### Що потрібно на ПК клубу
На кожному клубному ПК має бути встановлена бібліотека `pyautogui` (входить у `client/requirements.txt`):
```bash
pip install -r client/requirements.txt
```
Якщо `pyautogui` немає — клієнт продовжить працювати (стріми, скріншоти, процеси), але на команди миші відповідатиме помилкою.

### Поради для плавності
- Для комфортного керування тримайте трансляцію на **12–20 FPS** (кнопки FPS у вікні трансляції).
- Координати передаються у відсотках від кадру, тому клік влучає точно незалежно від роздільної здатності монітора ПК та розміру вікна браузера.
- На ПК з кількома моніторами керується саме той монітор, який транслюється (у трансляції видно один екран).

## 📱 Як користуватися Telegram-ботом
1. Відкрийте вашого бота в Telegram і натисніть `/start`.
2. Бот покаже список усіх комп'ютерів зі значками статусу:
   - 🟢 **Онлайн**
   - 🔴 **Офлайн**
3. Натисніть на потрібний ПК (наприклад, `🟢 PC-01`), щоб відкрити меню дій:
   - `📸 Скріншот` — бот надішле фото поточного робочого столу.
   - `🌐 Відкрити URL` — введіть адресу сайту, і вона відкриється на ПК.
   - `❌ Закрити процес` — введіть назву гри/процесу для закриття.
   - `📋 Процеси` — список найважчих запущених програм.
   - `🔄 Перезавантажити` / `⏻ Вимкнути` — керування живленням.

> 🖱 Керування мишею доступне лише у веб-панелі (у вікні трансляції екрану) — див. розділ «Керування мишею через веб-панель».
